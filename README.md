# Java Programming

Repositório com exercícios, exemplos e experimentos desenvolvidos ao longo do meu aprendizado de **Java e Programação Orientada a Objetos (POO)**.

Os conteúdos abordam fundamentos da linguagem, conceitos de orientação a objetos, herança, polimorfismo, coleções, mapas e outros recursos do Java, explorados por meio de exercícios práticos e pequenos exemplos.

## Conteúdos

* Fundamentos e sintaxe do Java
* Programação Orientada a Objetos
* Herança e polimorfismo
* Collections e Maps
* Membros estáticos e classes utilitárias
* Exercícios de algoritmos e programação

Os códigos estão organizados por tema e fonte de estudo, reunindo exercícios de diferentes materiais e atividades acadêmicas.
